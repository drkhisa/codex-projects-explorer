# История изменений

## 0.7.0 — 2026-11-06

- Во время ответа доступны `turn/steer` с `expectedTurnId` через Enter / «Уточнить сейчас» и отдельная видимая очередь следующих запросов. Очередь вмещает до 10 запросов и запускает `turn/start` последовательно после завершения хода и освобождения writer; элементы можно удалить, права проекта берутся заново перед каждой отправкой. Уточнение не имеет автоматического fallback на новый ход.
- Stop, ошибка и разрыв связи приостанавливают очередь, продолжение выполняется явно. Неизвестный результат не переотправляется: требуется проверить историю и удалить неопределённый элемент. Очередь существует только пока панель открыта, без сохранения между перезапусками.
- До 10 вложений на сообщение, включая папки/скиллы. Прикрепляются любые форматы до 50 МиБ на файл, paste-пакет — до 50 МиБ. Поддерживаемые изображения до 10 МиБ передаются нативно, известный текст до 256 КиБ — в контексте; крупные и бинарные файлы доступны инструментам через локальный путь, без автозапуска и декодирования binary как UTF-8.
- Пройдены 76 Node-тестов, 31 проверка синтаксиса JS и Python-проверки публикации/baseline. Нативный App Server 0.164.0-alpha.11.1 с изолированным synthetic SSE подтвердил steer в том же ходе, затем два queued turn: три completed, четыре provider requests. Настоящий изолированный VS Code 1.145.2 проверил send/steer/queue, 10 backup.awg во время ответа и сохранение нового черновика. Writer handoff, названия, clipboard, архив/удаление, кэш cold/warm и composer тоже прошли. Настоящая модель/аккаунт, живой ChatGPT, физическое системное Ctrl+V, macOS и установщики не проверялись.

## 0.6.0 — 2026-11-06

- Освобождение idle writer: принадлежащий расширению App Server запускается с CLI override `thread_unload_delay_secs=0`, пользовательский config не меняется. После завершения/закрытия чата выполняется unsubscribe с ожиданием `thread/closed`; новая отправка ждёт освобождения. Чужой активный клиент не прерывается, при конфликте сохраняются черновик и вложения.
- Ctrl+V добавляет скопированные изображения, текстовые файлы и документы в локальный чат Codex через прежнюю систему вложений. Проверяются формат, base64, размеры и число файлов; вставленные копии сохраняются для истории. До 8 элементов на сообщение, за одну вставку суммарно до 50 МБ; изображение до 10 МБ, текст до 256 КБ, документ до 50 МБ. Обычная вставка текста сохранена.
- Поле ввода сохраняет компактную высоту с внутренней прокруткой; отдельная кнопка «Развернуть / Свернуть» позволяет редактировать длинный запрос без потери текста и курсора. Старое autoheight больше не оставляет короткий текст в высоком поле.
- Кэш метаданных показывает дерево до ответа сервера; summaries JSONL повторно используются по size/mtime/ctime, индекс названий применяется отдельно. Фоновая сверка каталога остаётся для новых/изменённых/удалённых/архивных чатов; отсутствие RPC не обещается.
- Браузерный мост собирает доступные проекты ChatGPT и связи чатов; текст можно явно отправить из VS Code в выбранный исходный чат через DOM-форму. Неизвестный исход блокирует повтор до проверки пользователем; просроченная команда не нажимает отправку. Loopback, Host/Origin, bearer/HMAC и ограничения размера сохранены. Полнота аккаунта не гарантируется, онлайн-вложения и архив/удаление ChatGPT не добавлены.
- Индикаторы активности у чата, категории, проекта, отдельной и онлайн-группы видны и в свёрнутом дереве, сбрасываются при отсутствии активности.
- Отдельный «Архив Codex» показывает архивные чаты по исходным проектам. Восстановление и окончательное удаление архивного чата доступны из меню. Именованное модальное подтверждение предупреждает об удалении истории и дочерних чатов; файлы проекта сохраняются. Active/read-only/home/source guards и повторная проверка архива предшествуют `thread/delete`; отмена/ошибка не запускает ручного удаления истории.
- Пройдены 67 Node-тестов, 31 проверка синтаксиса JS и Python-проверки публикации/baseline. В изолированном настоящем VS Code 1.145.2 с двумя нативными App Server и локальным статическим SSE проверены writer handoff, PNG/TXT через ClipboardEvent и отправка, названия/черновик, архив/удаление синтетического чата и показ кэша при повторном запуске. Браузерный протокол проверен на синтетическом DOM/HTTP. Настоящая модель, аккаунт, живой ChatGPT, обычный профиль, установщики, macOS, сопряжение браузера и физическое Ctrl+V не проверялись.
- После обновления требуется перезагрузка окна VS Code, обновление браузерного компонента до 0.6.0 и всех открытых вкладок ChatGPT: старый протокол новых команд не поддерживает.

## 0.5.5 — 2026-11-06

- Исправлен пропущенный в 0.5.4 путь первой отправки: после принятия сервером первого текстового сообщения его сокращённый текст сразу становится подписью дерева, вкладки и заголовка без ручного обновления и события переименования. Следующие сообщения её не заменяют; отклонённая отправка подпись не меняет. Заданное имя имеет приоритет, генерация имени моделью не добавлялась.

- Пройдены 22 синтетических теста (9 на жизненный цикл, 13 на название) и проверка синтаксиса 31 JS-файла. Нативный App Server с изолированными данными и локальным синтетическим HTTP/SSE-ответом завершил ход и обновил обе подписи через реальные Backend/ChatSession.
- Дополнительно пройдена интеграционная UI-проверка в настоящем VS Code 1.145.2 с изолированным профилем: создание чата, реальная кнопка отправки, названия дерева/вкладки/документа/h1 после завершения хода и серверное переименование с сохранением черновика. Настоящая модель, аккаунт, обычный профиль, установщики, macOS, браузер и сопряжение не проверялись.
