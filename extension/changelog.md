# История изменений

## 0.5.4 — 2026-11-06

- Исправлено расхождение названия: дерево уже обновлялось, но открытая вкладка и заголовок внутри чата продолжали показывать ID. Имя или текст первого сообщения теперь синхронизируются при обновлении списка, повторном выборе чата и событии переименования.
- Обновление названия не перезагружает историю и не сбрасывает черновик. Имя передаётся как текст; переименование до готовности webview также учитывается.
- Добавлены 6 тестов названия; вместе с 9 проверками жизненного цикла проходят 15 синтетических тестов. На изолированном App Server подтверждён формат события переименования, без запуска модели и чтения реальной истории.

## 0.5.3 — 2026-11-06

- Исправлен жизненный цикл чата: первый запрос без сохранённого rollout и повторное открытие чата на том же сервере без повторного захвата writer. Конфликт с другим клиентом остаётся явной ошибкой.
- Восстановлена упаковка общего комплекта Windows/Mac без новых зависимостей, с проверкой вложенных архивов и SHA-256. Инструкции приведены к фактическим проверкам восстановленного репозитория.

## 0.5.2 — 2026-11-06

- В проекте: закреплённые чаты → категории → остальные чаты → скиллы. Закреп из категории показан единожды, назначение категории сохраняется. Отдельный запоминаемый порядок закрепов.
- Общий архив с Windows/Mac в отдельных папках, двумя текстовыми инструкциями, папкой и ZIP браузерного компонента. Mac-сценарий установки VSIX двойным кликом с выбором VS Code при необходимости.
- Убран длинный блок установки компонента из окна подключения. Явно отмечено: обычная установка браузерного расширения двойным кликом остаётся заблокированной отсутствием публикации в магазине. Установщик браузера не заявляется готовым.

## 0.5.1 — 2026-11-06

- Возвращены старые локальные записи source=vscode без originator в Codex: на пользовательском отчёте 219 Codex + 5 Work, без потери 79 старых чатов.
- Крутилки: немедленные события runtime, ожидание разрешения/ответа, чтение приращений внешних журналов раз в 2 секунды. notLoaded отдельного сервера не гасит внешнюю работу; устаревшее начало хода помечается неподтверждённым.
- Браузерное расширение: подключение без копирования кода, запоминание в SecretStorage/хранилище компонента, автоматическое восстановление с HMAC после перезапуска. Постоянная папка компонента и резервный ручной способ. Полная онлайн-история и отправка из VS Code по-прежнему не реализованы.
- Файлы: дерево изменений Git справа, метки в основном дереве, встроенное сравнение HEAD с рабочей версией; патчи действий/ответа Codex открываются отдельной вкладкой diff.
- Видимая строка «＋ Новый чат», кнопка в заголовке и «＋» у проекта. Настоящий чат вне проекта с projectId:null показывается плоско и сохраняет эту принадлежность.

## 0.5.0 — 2026-11-06

- Экспериментальный браузерный мост ChatGPT: проекты и чаты отображённых страниц, текст выбранной онлайн-переписки в центре VS Code, переход к продолжению в исходном ChatGPT.
- Одноразовое локальное сопряжение и отдельный ключ сеанса; данные только из одной выбранной вкладки. Никакого чтения cookies/auth.json и вызовов частных API. Отключение очищает снимки.
- Отдельное дерево онлайн-данных; онлайн-идентификаторы не передаются в Codex CLI и App Server.
- Прокрутка текущих загруженных списков из браузерного расширения. Явная отметка неполноты: это не подтверждённая полная синхронизация аккаунта.
- Компонент для Chrome/Edge включён в VSIX и Windows-архив, пошаговое подключение открывается в центре VS Code.
- Авторизованная история реального аккаунта в среде сборки недоступна; живое чтение и установка компонента требуют проверки на компьютере пользователя. Отправка из VS Code и онлайн-управление пока не реализованы.

## 0.4.1 — 2026-11-06

- Убран общий fallback source=vscode → Codex: метка встречается у нескольких клиентов и не определяет продукт.
- Учтён codex_work_desktop как предварительно сопоставленный локальный Work; основание видно в подсказке. Доступно явное ручное назначение «Источник не определён».
- При конфликте явного клиента Codex с меткой источника ChatGPT используется неопределённый раздел.
- По присланной структуре метаданных: 224 записи сохраняются, разбивка — 140 Codex, 5 локальных Work, 79 неопределённых. Новая регрессионная проверка.
- Полная онлайн-история аккаунта этим исправлением не подключается.

## 0.4.0 — 2026-11-06

- Категории внутри проектов: создание/переименование, перенос через меню или перетаскивание, новый чат в категории, удаление категории с сохранением чатов. Принадлежность и порядок сохраняются отдельно для каждого проекта.
- Доступ теперь общий для всех чатов проекта, включая новые и рабочие деревья с тем же projectId. Выбор синхронизируется с открытыми вкладками, действующие задачи сохраняют прежние права. Старый полный доступ отдельной вкладки не переносится автоматически на проект.
- Круглая кнопка ↓ к последнему сообщению; потоковые ответы не сбрасывают чтение старой истории.
- Включает исправление 0.3.1: источник истории аккаунта ChatGPT не подключён, и локальный фильтр не выдаётся за нулевую историю аккаунта.

## 0.3.1 — 2026-11-06

- Исправлена вводящая в заблуждение надпись «В разделе ChatGPT пока нет чатов»: локальный фильтр не проверяет историю аккаунта.
- Статус «История аккаунта ChatGPT не подключена» виден и при пустом, и при непустом локальном списке. Счётчики аккаунта обозначены неизвестными, локальные считаются отдельно.
- Добавлено копирование диагностики источников с агрегированными метками, без текстов, названий чатов, вложений и токенов.
- Команды создания проекта/чата в режиме ChatGPT не перенаправляются незаметно в каталог Codex.
- Это исправление индикации и диагностики; загрузка полной истории аккаунта ChatGPT не реализована.

## 0.3.0 — 2026-11-06

- Раздельные Codex / ChatGPT; неопределённые источники отдельно, ручное назначение раздела.
- Настоящий каталог project/list, имена и пустые проекты; создание новой папки и канонического проекта с выбором места через project/create. Новый чат с projectId.
- Убраны промежуточные new-chat; архивирование/восстановление, закрепы, перетаскивание и сохранение ручного порядка. Новые чаты всегда перед сохранённым порядком.
- Крутилка у работающих чатов и проектов: события собственной сессии и доступные статусы сервера.
- Изображения и документы карточками в обоих направлениях; увеличение изображений, открытие документов, результаты генерации изображений.
- Меню плюса: файлы, папка, код, поиск доступных скиллов и плагинов, структурированная передача выбранного пакета.
- Ветка скиллов каждого проекта: проектные и общие доступные, включая явную метку выключенных.
- Принимаемые Tab подсказки по последнему ответу без автоматической отправки.
- Включает исправления хронологии и правое файловое дерево версии 0.2.1; Windows-установщик с исправленным обнаружением редактора r2.

## 0.2.1 — 2026-11-06

- История сообщений и вызовов инструментов объединена по исходному порядку событий для App Server и старых JSONL. Вывод команды прикрепляется к соответствующему вызову.
- Подряд идущие действия свёрнуты в один блок на своём месте между сообщениями. Исправлены одинаковые подписи «Команда · сохранено» для разных инструментов.
- Значок папки проекта открывает дерево файлов справа в том же окне. Папки раскрываются по запросу, файлы открываются в обычном редакторе слева от дерева.
- Повторное нажатие значка переключает проект без новых окон; доступны все корни проекта, обновление, отслеживание создания/удаления и управление клавиатурой.
- Сохранено исправленное обнаружение VS Code в Windows-установщике r2.

## 0.2.0 — 2026-11-06

- Полноценный чат в центральной вкладке: отправка в исходную сессию, каталог моделей, глубина размышлений, потоковая выдача, остановка и вложения.
- Подтверждения действий и уточняющие вопросы в центральном интерфейсе.
- Вид диалога приближен к приложению Codex: открытые ответы и компактные пользовательские блоки справа.
- Приоритет канонического projectId при объединении рабочих папок. Удалён ошибочный ярлык «без привязки» для именованных папок проектов.
- CLI-продолжение использует --no-daemon для неполного локального пакета из официального расширения.
- Windows-установщик с графическим окном и автоматическим обнаружением VS Code; универсальный VSIX для Mac/Windows/Linux.

## 0.1.1 — 2026-11-06

- На Windows продолжение сессии запускается внутри PowerShell с `-NoExit`, чтобы терминал оставался открытым и показывал настоящую ошибку Codex.
- Для путей к бинарному файлу используется экранирование литералов PowerShell; вложенные идентификаторы сессии из родительского процесса не наследуются.
- Нераспознанные папки перенесены в единую свёрнутую ветку; все чаты остаются доступны в дереве и поиске.
- Добавлена команда назначения названия проекта прямо из контекстного меню папки.
- Версия в диагностике и имя собираемого пакета берутся из package.json.
- Код выхода 1 из предыдущей версии сам по себе не считается доказательством конкретной причины сбоя. Повторный запуск нужен для получения текста ошибки на Windows.
