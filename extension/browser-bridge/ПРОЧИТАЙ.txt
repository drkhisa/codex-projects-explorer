ВНИМАНИЕ: ниже описана ручная установка для разработчика. Обычная установка
двойным кликом пока недоступна, пока компонент не опубликован в магазине.

ChatGPT → VS Code 0.5.4

УСТАНОВКА ОДИН РАЗ (Chrome / Edge / Яндекс, Windows и Mac)

Предпочтительно: установите VSIX, в VS Code откройте «Подключить онлайн ChatGPT».
Раскройте «Первая установка браузерного расширения» и нажмите «Открыть папку
расширения». Путь автоматически скопируется. Он постоянный: при следующих
обновлениях VS Code не нужно искать новую папку в Downloads.

В браузере откройте chrome://extensions (Chrome), edge://extensions (Edge)
или browser://extensions (Яндекс). Включите режим разработчика, нажмите
«Загрузить распакованное расширение», вставьте скопированный путь.
Если используете этот отдельный ZIP, распакуйте его в постоянную папку и
выберите папку, в которой находится manifest.json. Не удаляйте её после установки.
Safari/Firefox пока не поддерживаются. При обновлении с 0.5.0 загрузите новый
компонент один раз; старый компонент можно удалить.

ПОДКЛЮЧЕНИЕ

В VS Code нажмите «Подключить браузер». Браузер подключится сам и откроет ChatGPT.
Копировать коды не нужно. Войдите в свой ChatGPT, если вход ещё не выполнен.
После этого просто пользуйтесь ChatGPT как обычно: данные загруженных страниц
и текст текущих чатов автоматически попадают в раздел ChatGPT в VS Code.
Соединение запоминается и восстанавливается после перезапусков браузера/VS Code.
Popup расширения показывает состояние и содержит резервные действия.

ОГРАНИЧЕНИЯ

Это ещё не полный серверный архив. Непрогруженные проекты/страницы, свёрнутые
блоки и виртуализированные сообщения могут отсутствовать. Счётчики описывают
только полученные записи. Отправка, выбор модели и вложения остаются в ChatGPT.
Данные передаются из вкладок ChatGPT этого браузерного профиля. При смене
аккаунта сначала выполните в VS Code «Отключить онлайн ChatGPT и очистить снимки».

БЕЗОПАСНОСТЬ

Cookies, пароли, auth.json и ключи аккаунта не читаются; частные API не вызываются.
Передача идёт только на 127.0.0.1. Ключ сопряжения хранится в SecretStorage VS Code
и локальном хранилище браузерного расширения. При восстановлении используется
HMAC; сохранённый ключ в запрос не отправляется. Тексты снимков хранятся только
в памяти до закрытия VS Code. Отключение в VS Code забывает сопряжение и очищает
полученные снимки. Если окно VS Code уже заняло порт, используйте это окно.

В выпуске 0.5.4 поведение браузерного компонента не изменялось.
При подготовке комплекта проверяются структура, синтаксис и содержимое архивов.
Установка, реальное HTTP-соединение и разметка авторизованного аккаунта
не проверялись. Изменения сайта могут потребовать обновления адаптера.
