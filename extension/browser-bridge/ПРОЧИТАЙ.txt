ВНИМАНИЕ: ниже описана ручная установка для разработчика. Обычная установка
двойным кликом пока недоступна, пока компонент не опубликован в магазине.

ChatGPT → VS Code 0.6.0

ОБНОВЛЕНИЕ С ПРЕДЫДУЩЕЙ ВЕРСИИ
Обновите VSIX и браузерный компонент до 0.6.0, перезагрузите окно VS Code
и все открытые вкладки ChatGPT. Старый протокол не поддерживает новые команды
сбора проектов и текстовой отправки. Установщик VSIX браузер не обновляет.

УСТАНОВКА ОДИН РАЗ (Chrome / Edge / Яндекс, Windows и Mac)

Предпочтительно: установите VSIX, в VS Code откройте «Подключить онлайн ChatGPT».
Раскройте «Первая установка браузерного расширения» и нажмите «Открыть папку
расширения». Путь автоматически скопируется. Он постоянный: при следующих
обновлениях VS Code не нужно искать новую папку в Downloads.

В браузере откройте chrome://extensions (Chrome), edge://extensions (Edge)
или browser://extensions (Яндекс). Включите режим разработчика, нажмите
«Загрузить распакованное расширение», вставьте скопированный путь.
Если используете этот отдельный ZIP, распакуйте его в постоянную папку и
выберите папку, в которой находится manifest.json. Не удаляйте её после установки.
Safari/Firefox пока не поддерживаются. При обновлении с 0.5.0 загрузите новый
компонент один раз; старый компонент можно удалить.

ПОДКЛЮЧЕНИЕ

В VS Code нажмите «Подключить браузер». Браузер подключится сам и откроет ChatGPT.
Копировать коды не нужно. Войдите в свой ChatGPT, если вход ещё не выполнен.
После этого просто пользуйтесь ChatGPT как обычно: данные загруженных страниц
и текст текущих чатов автоматически попадают в раздел ChatGPT в VS Code.
Соединение запоминается и восстанавливается после перезапусков браузера/VS Code.
Popup расширения показывает состояние и содержит резервные действия.
После подключения запускается сбор проектов: раскрываются доступные списки,
их страницы просматриваются в отдельной неактивной вкладке. Повторить сбор можно
кнопкой «Загрузить проекты и их чаты» в VS Code или popup браузерного компонента.
Счётчики и статус показывают только обнаруженные записи. Если проектов нет,
откройте раздел «Проекты» в ChatGPT и повторите сбор. Длинные списки ограничены
временем одного прохода; остальные проекты можно открыть вручную. При переходе
в служебную вкладку сбор останавливается и не закрывает её.

ОТПРАВКА ТЕКСТА В ОНЛАЙН-ЧАТ

Откройте онлайн-чат в VS Code, введите текст и нажмите «Отправить в ChatGPT».
Через локальный мост передаётся только этот текст. Компонент находит исходный
чат в подключённом профиле или открывает его в новой неактивной вкладке.
При резервном подключении одной вкладки нужный чат надо открыть именно в ней.
Используется обычная форма ChatGPT: без cookies, токенов аккаунта и частных API.
Существующий черновик, вложение или текущая генерация блокируют отправку.
Модель, файлы и изображения выбираются в браузере; локальная история Codex
в аккаунт ChatGPT не переносится.

Успех означает появление нового сообщения в исходной странице ChatGPT;
сохранение на сервере отдельно не проверяется. При неизвестном результате
автоповтора нет: сначала проверьте исходный чат, затем подтвердите проверку
кнопкой панели. Просроченная команда не нажимает отправку. Если форма была
заполнена, но отправка не состоялась, текст остаётся в браузере для проверки.
Обновление снимков не стирает черновик VS Code.

ОГРАНИЧЕНИЯ

Это ещё не полный серверный архив. Непрогруженные проекты/страницы, свёрнутые
блоки и виртуализированные сообщения могут отсутствовать. Счётчики описывают
только полученные записи. Сайт может менять разметку и способы ленивой загрузки;
полнота аккаунта не подтверждается даже после успешного прохода.
Данные передаются из вкладок ChatGPT этого браузерного профиля. При смене
аккаунта сначала выполните в VS Code «Отключить онлайн ChatGPT и очистить снимки».

БЕЗОПАСНОСТЬ

Cookies, пароли, auth.json и ключи аккаунта не читаются; частные API не вызываются.
Передача идёт только на 127.0.0.1. Ключ сопряжения хранится в SecretStorage VS Code
и локальном хранилище браузерного расширения. При восстановлении используется
HMAC; сохранённый ключ в запрос не отправляется. Тексты снимков хранятся только
в памяти до закрытия VS Code. Отключение в VS Code забывает сопряжение и очищает
полученные снимки. Если окно VS Code уже заняло порт, используйте это окно.

22 регрессионные проверки используют синтетический DOM и локальный HTTP-мост
с обеих сторон: проекты, отправка, её неопределённый исход и защиты протокола.
Авторизованный живой ChatGPT, установка и сопряжение браузера не проверялись;
реальные сообщения аккаунту при тестах не отправлялись. Онлайн-вложения,
архивирование и удаление онлайн-чатов не реализованы. Разметка сайта может
потребовать адаптации. Полный архив аккаунта не гарантируется.
