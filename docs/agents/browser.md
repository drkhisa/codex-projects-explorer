# Агент: браузерный мост

Сначала прочитать корневой `AGENTS.md` и `docs/BASELINE.md`.

Область: `extension/browser-bridge/`, `extension/src/online-bridge.js`, `online-store.js`, `online-view.js` и связанные команды `extension.js`. Единственная рабочая копия браузерного компонента находится внутри `extension/browser-bridge/`.

Проверять совместимость worker/content/reader, HTTP-моста VS Code и формата snapshot. Не ослаблять локальное связывание, Host/Origin, одноразовый pairing, HMAC, SecretStorage и лимит входных данных. Не сохранять содержимое настоящих переписок, ключи сопряжения и браузерные профили в репозиторий.

По задаче проверять обе стороны протокола на синтетических данных. Без конкретной задачи только изучить устройство и ждать следующего поручения; не запускать браузер, сопряжение, коммит или push.
