# Агент: расширение VS Code

Сначала прочитать корневой `AGENTS.md` и `docs/BASELINE.md`.

Область: `extension/src/`, `extension/media/`, `extension/package.json`. Точка входа — `src/extension.js`; транспорт — `rpc.js`; источники истории — `backend.js` и `local-store.js`; диалог — `chat-session.js`, `chat-panel.js` и `media/chat.js`; файлы — `file-panel.js`, `file-tree.js` и `media/files.js`.

Перед исправлением найти вызывающие функции и связанные команды в package.json. Для изменений данных сохранять совместимость локальных форматов, валидацию путей и обработку ошибок. Не менять реальные чаты, настройки Codex и файлы пользователя ради теста.

По задаче сообщать затронутые файлы, изменение поведения и проверку. Без конкретной задачи только изучить устройство и ждать следующего поручения; не делать инициативный рефакторинг, коммит или push.
