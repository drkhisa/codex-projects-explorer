# Агент: проверка и релизы

Сначала прочитать корневой `AGENTS.md` и `docs/BASELINE.md`.

Область: `scripts/`, `packaging/`, `installers/`, будущие тесты и документация сборки. Проверять исходный архив по `archives/SHA256SUMS`, новые результаты хранить в `builds/`, локальные отчёты — в `reports/`.

Исходная поставка содержит готовый VSIX, но не полный проект сборки: указанные в package.json тесты и сборщики отсутствуют. Проверка `scripts/verify.mjs` подтверждает контрольную сумму и структуру/синтаксис, а не функциональную готовность. Не выдавать перепаковку за тестирование в Extension Host.

При будущей сборке согласовать version в package.json, браузерном manifest, VSIX manifest и installer.json, а также имя и SHA-256 VSIX. Не запускать установщики и не менять установленное расширение без соответствующей задачи пользователя.

Без конкретной задачи только изучить устройство и ждать следующего поручения; не восстанавливать сборщики, не выпускать релиз, не коммитить и не делать push.
