CODEX PROJECTS EXPLORER 0.7.1 — WINDOWS

1. УСТАНОВИТЬ VS CODE
Откройте https://code.visualstudio.com/download
Скачайте Windows User Installer x64 и установите его. Требуется 64-битная
Windows 10/11. Запустите VS Code.

2. УСТАНОВИТЬ ОФИЦИАЛЬНЫЙ CODEX
В VS Code нажмите Ctrl+Shift+X. В поиск вставьте @id:openai.chatgpt
Установите расширение Codex от OpenAI. Откройте его панель, нажмите
Sign in with ChatGPT и войдите в свой аккаунт через браузер.

3. УСТАНОВИТЬ НАШЕ РАСШИРЕНИЕ
Распакуйте общий архив целиком. Откройте папку Windows.
Оставьте VS Code запущенным. Дважды нажмите Установить.cmd.
В окне установщика нажмите Установить. После завершения полностью закройте
VS Code и откройте его заново.
Если редактор не найден, нажмите Выбрать… и укажите Code.exe, обычно:
%LOCALAPPDATA%\Programs\Microsoft VS Code\Code.exe
или C:\Program Files\Microsoft VS Code\Code.exe
Не выбирайте установочный EXE редактора. Не открывайте VSIX двойным кликом:
он может запустить установщик другого Visual Studio.

4. УСТАНОВИТЬ GIT ДЛЯ ПРОСМОТРА ИЗМЕНЕНИЙ
Если Git ещё не установлен: https://git-scm.com/install/windows
Скачайте x64 Setup, установите со стандартными настройками и перезапустите VS Code.
Наше сравнение показывает HEAD и рабочую версию в локальном Git-репозитории.

5. НАЧАТЬ РАБОТУ
Слева нажмите Проекты Codex. Выберите раздел Codex и нужный чат.
Новый чат вне проекта: ＋ Новый чат → Новый чат вне проекта.
Новый чат в проекте: наведите на проект и нажмите ＋ справа.
Порядок проекта: закреплённые чаты → категории → остальные чаты → скиллы.
Закреп из категории показан один раз сверху. При откреплении возвращается
в свою категорию. Ручной порядок закрепов запоминается отдельно.
Кнопка Изменения в чате открывает файлы/изменения справа; нажатие изменённого
файла открывает сравнение. Локальные чаты читаются с этого компьютера.

6. БРАУЗЕРНОЕ РАСШИРЕНИЕ — ГРАНИЦА ЭТОЙ СБОРКИ
В этой же папке лежат browser-bridge и Codex-Projects-Browser-0.7.1.zip.
Это готовые файлы браузерного компонента. Но установка в браузер двойным
кликом с выбором установленного браузера ЕЩЁ НЕ РЕАЛИЗОВАНА.
Для штатной внешней установки Chrome на Windows/macOS нужна публикация
в Chrome Web Store. Опубликованной карточки и ID у компонента пока нет.
Добавление ZIP/CRX в архив не снимает это ограничение. Готового универсального
установщика браузерного расширения в этой сборке нет; Установить.cmd ставит
только расширение VS Code. Политики и безопасность браузеров не изменяются.
Ручной способ для разработчика описан в browser-bridge/ПРОЧИТАЙ.txt; он не
выдаётся за запрошенную установку двойным кликом.

Если компонент уже установлен: Ctrl+Shift+P → Codex Projects: Подключить
онлайн ChatGPT → Подключить браузер. Соединение запоминается.
Браузерный протокол совместим с 0.6.0. При переходе с 0.5.x обновите
компонент и вкладки ChatGPT; компонент в текущем комплекте — 0.7.1.
Нажмите «Загрузить проекты и их чаты». Сбор ограничен доступными страницами,
полнота аккаунта не гарантируется. В выбранном онлайн-чате можно явно отправить
текст кнопкой «Отправить в ChatGPT». При неизвестном исходе проверьте исходный
чат перед новой отправкой. Онлайн-вложения и выбор модели доступны в браузере.

7. ПРОВЕРКА
В списке расширений должен быть Codex Projects Explorer версии 0.7.1.
Если локальная история пуста: ⋯ в Проектах Codex → Выбрать папку данных Codex.
Обычно это %USERPROFILE%\.codex. Вход в тот же аккаунт не переносит локальную
историю с другого компьютера. При ошибке: ⋯ → Показать диагностику.

Фактические проверки выпуска перечислены в общем файле СНАЧАЛА ПРОЧИТАЙ.txt.
Пройдены 85 Node-тестов и 31 проверка синтаксиса JS. В изолированном VS Code
1.145.2 проверены названия/черновик, writer handoff, ClipboardEvent PNG/TXT,
кэш и архивирование/удаление синтетического чата с сохранением файлов проекта. Установщик, обычный профиль, настоящая модель и аккаунт
не проверялись. Установщик — сценарий, не подписанный EXE.

НОВЫЕ ЛОКАЛЬНЫЕ ВОЗМОЖНОСТИ
Ctrl+C копирует, Ctrl+V вставляет изображение/файл в поле сообщения Codex.
Проверьте карточку вложения, затем отправьте. В переключателе разделов доступен
«Архив Codex» по проектам. Удаление навсегда требует подтверждения и удаляет
историю с дочерними чатами; файлы проекта сохраняются. Физическое Ctrl+V
и пользовательский профиль отдельно не проверялись; подробности в общем ПРОЧИТАЙ.

НОВОЕ В 0.7.1
Во время ответа Ctrl+Enter / «Уточнить сейчас» уточняет текущий ход, Enter / «В очередь»
ставит отдельный следующий запрос после завершения/release предыдущего.
Очередь до 10 запросов видна и поддерживает удаление элемента. Stop/ошибка/разрыв
ставят её на паузу; продолжение явно. Неизвестный исход сначала проверить
по истории и убрать неопределённый элемент — автоповтора нет. Очередь только
пока панель открыта, без сохранения между перезапусками.
Любые форматы до 50 МиБ/файл, до 10 вложений с папками/скиллами на сообщение;
paste суммарно до 50 МиБ. Изображения до 10 МиБ нативно, известный текст
до 256 КиБ в контексте; остальное — путь для инструментов без автозапуска.
Нативный App Server и изолированный VS Code проверили steer/queue и 10 .awg.
Настоящая модель/аккаунт, физическое Ctrl+V, macOS и установщики не проверялись.

КЛАВИШИ И ОГРАНИЧЕНИЕ 0.7.1
Enter всегда ставит в очередь (в простое она запускается сразу), Ctrl+Enter
уточняет текущий ответ либо отправляет новый в простое, Shift+Enter — строка.
Fn+Enter эквивалентен Ctrl+Enter только при переданном Fn; скрытый аппаратный
Fn определить нельзя. Удержание Enter не создаёт повторные запросы.
Межпроцессный writer НЕ ИСПРАВЛЕН: другой клиент, включая Desktop, может
удерживать его даже в простое. Освобождается только собственный сервер
расширения; для исходного чата требуется освобождение владельцем. Скрытого
fork, перехвата writer или автоматического изменения пользовательских чатов нет.
Проверены 85 Node-тестов и реальные KeyboardEvent в изолированном VS Code;
физический Fn, настоящий аккаунт, macOS и установщики не проверялись.

ПЕРЕДАЧА ЧЕРНОВИКА В ИСХОДНЫЙ ЧАТ DESKTOP
При writer-конфликте нажмите «Продолжить в Codex с черновиком»; для элемента
очереди — его «В Codex». Открывается тот же ID, без fork и автоотправки.
Если полный URI длиннее 1800 символов, по этому нажатию весь draft копируется
в системный буфер, чат открывается без query; вставьте Ctrl+V и отправьте.
Вложения идут текстом как локальные пути/контекст, не карточками Desktop.
Draft/вложения/очередь в VS Code сохраняются. ПОСЛЕ ОТПРАВКИ В DESKTOP УДАЛИТЕ
ЭЛЕМЕНТ ОЧЕРЕДИ ВРУЧНУЮ, чтобы не отправить его повторно. Чужой процесс не
останавливается, lock не снимается. Установленный parser поддерживает
prefillPrompt; реальный Desktop с пользовательской историей не открывался.
Настоящий VS Code с двумя native App Server и stub Desktop opener проверил
кнопки и сохранение данных; OS openExternal/clipboard проверены Node-стабами.
