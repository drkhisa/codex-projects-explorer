CODEX PROJECTS EXPLORER 0.7.1 — MAC

1. ПРОВЕРИТЬ macOS
 → Об этом Mac. Актуальный VS Code требует macOS 12 или новее.
На macOS Catalina 10.15 этот комплект с актуальными зависимостями не обещает
работать; совместимость старых версий здесь не проверена.

2. УСТАНОВИТЬ VS CODE
Откройте https://code.visualstudio.com/download
Скачайте macOS Universal. Откройте DMG, перенесите Visual Studio Code.app
в Программы / Applications. Запустите редактор из Программ.

3. УСТАНОВИТЬ ОФИЦИАЛЬНЫЙ CODEX
В VS Code нажмите Cmd+Shift+X. В поиск вставьте @id:openai.chatgpt
Установите Codex от OpenAI. Откройте его панель, нажмите Sign in with ChatGPT,
войдите в свой аккаунт в браузере и вернитесь в редактор.

4. УСТАНОВИТЬ НАШЕ РАСШИРЕНИЕ
Распакуйте общий архив, откройте папку Mac.
Дважды нажмите Установить.command. Это сценарий, который запускается через
Терминал; вручную вводить команды для установки VSIX не требуется.
Он ищет VS Code в Программах и при необходимости предлагает выбрать редактор.
Устанавливается только наше расширение VS Code, не браузерный компонент.
После сообщения об успехе полностью закройте VS Code через Cmd+Q и откройте заново.
Сценарий не подписан и на настоящем Mac здесь не запускался. Если система
не разрешает его запуск, используйте ручную установку VSIX ниже.

РУЧНАЯ УСТАНОВКА VSIX
В VS Code нажмите Cmd+Shift+P. В появившейся строке команд введите
Extensions: Install from VSIX...
Нажмите Enter, выберите codex-projects-explorer-0.7.1.vsix из папки Mac,
нажмите Установить. Закройте редактор через Cmd+Q и откройте снова.

5. УСТАНОВИТЬ GIT ДЛЯ ПРОСМОТРА ИЗМЕНЕНИЙ
Если Git не установлен, откройте Программы → Утилиты → Терминал и выполните:
xcode-select --install
В появившемся окне нажмите Установить и дождитесь завершения.
Если инструменты уже установлены, повторная установка не нужна.

6. НАЧАТЬ РАБОТУ
Слева нажмите Проекты Codex. Раздел Codex читает локальную историю этого Mac.
Сам по себе вход в тот же аккаунт не загружает историю с Windows.
Новый чат вне проекта: ＋ Новый чат → Новый чат вне проекта.
Новый чат в проекте: наведите на проект и нажмите ＋ справа.
Порядок: закреплённые чаты → категории → остальные чаты → скиллы.
Закреплённый чат из категории показан единожды сверху; после открепления
возвращается в категорию. Ручной порядок закрепов запоминается.
Кнопка Изменения в чате открывает дерево файлов и изменения Git справа.

7. БРАУЗЕРНОЕ РАСШИРЕНИЕ — ГРАНИЦА ЭТОЙ СБОРКИ
В папке Mac приложены browser-bridge и Codex-Projects-Browser-0.7.1.zip.
Установщика браузерного расширения двойным кликом с выбором браузера здесь
ЕЩЁ НЕТ. Для обычной внешней установки в Chrome на macOS требуется публикация
в Chrome Web Store. Компонент ещё не опубликован; карточки и ID нет.
ZIP/CRX не устанавливается в Chrome просто двойным кликом. Установить.command
не объявляет браузерное расширение установленным. Политики браузеров не меняются.
Ручной способ описан в browser-bridge/ПРОЧИТАЙ.txt; это временный путь
для разработчика, а не запрошенная обычная установка.
Safari/Firefox этим компонентом не поддерживаются.

Если компонент уже установлен: Cmd+Shift+P → Codex Projects: Подключить онлайн
ChatGPT → Подключить браузер. Соединение запоминается. Если страница открылась
в Safari, перенесите её адрес в браузер с установленным компонентом.
Браузерный протокол совместим с 0.6.0. При переходе с 0.5.x обновите
компонент и вкладки ChatGPT; компонент в текущем комплекте — 0.7.1.
Нажмите «Загрузить проекты и их чаты». Доступна явная текстовая отправка
кнопкой «Отправить в ChatGPT». При неизвестном исходе проверьте исходный чат.
Полнота аккаунта не гарантируется; выбор модели и онлайн-вложения — в браузере.

8. ПРОВЕРКА
В расширениях должна отображаться версия Codex Projects Explorer 0.7.1.
Если история пуста: ⋯ в Проектах Codex → Выбрать папку данных Codex.
Обычный путь: ~/.codex. В диалоге Finder путь можно ввести через Cmd+Shift+G.
Если нет проектов/чатов с другого компьютера, это не доказывает их отсутствие
в аккаунте: локальное хранилище не синхронизируется автоматически.

Фактические проверки выпуска перечислены в общем файле СНАЧАЛА ПРОЧИТАЙ.txt.
Синтаксис bash, запуск сценария и VS Code Extension Host на настоящем Mac,
установка в браузере и авторизованная онлайн-история не проверялись.

ЛОКАЛЬНЫЕ ВОЗМОЖНОСТИ
Кэш показывает дерево до фоновой сверки. «Архив Codex» отображает архивные чаты
по проектам, позволяет восстановить или удалить навсегда с подтверждением.
Удаляется история и дочерние чаты, файлы проекта остаются. Вставка файлов
из буфера реализована в webview, но нативные сочетания и форматы буфера macOS,
как и сам выпуск на настоящем Mac, не проверялись. Подробные проверки — в общем ПРОЧИТАЙ.

НОВОЕ В 0.7.1
Во время ответа Ctrl+Enter / «Уточнить сейчас» уточняет текущий ход, Enter / «В очередь»
ставит отдельный следующий запрос после завершения/release предыдущего.
Очередь до 10 запросов видна и поддерживает удаление элемента. Stop/ошибка/разрыв
ставят её на паузу; продолжение явно. Неизвестный исход сначала проверить
по истории и убрать неопределённый элемент — автоповтора нет. Очередь только
пока панель открыта, без сохранения между перезапусками.
Любые форматы до 50 МиБ/файл, до 10 вложений с папками/скиллами на сообщение;
paste суммарно до 50 МиБ. Изображения до 10 МиБ нативно, известный текст
до 256 КиБ в контексте; остальное — путь для инструментов без автозапуска.
Нативный App Server и изолированный VS Code проверили steer/queue и 10 .awg.
Настоящая модель/аккаунт, физическое Ctrl+V, macOS и установщики не проверялись.

КЛАВИШИ И ОГРАНИЧЕНИЕ 0.7.1
Enter всегда ставит в очередь (в простое она запускается сразу), Ctrl+Enter
уточняет текущий ответ либо отправляет новый в простое, Shift+Enter — строка.
Fn+Enter эквивалентен Ctrl+Enter только при переданном Fn; скрытый аппаратный
Fn определить нельзя. Удержание Enter не создаёт повторные запросы.
Межпроцессный writer НЕ ИСПРАВЛЕН: другой клиент, включая Desktop, может
удерживать его даже в простое. Освобождается только собственный сервер
расширения; для исходного чата требуется освобождение владельцем. Скрытого
fork, перехвата writer или автоматического изменения пользовательских чатов нет.
Проверены 85 Node-тестов и реальные KeyboardEvent в изолированном VS Code;
физический Fn, настоящий аккаунт, macOS и установщики не проверялись.

ПЕРЕДАЧА ЧЕРНОВИКА В ИСХОДНЫЙ ЧАТ DESKTOP
При writer-конфликте нажмите «Продолжить в Codex с черновиком»; для элемента
очереди — его «В Codex». Открывается тот же ID, без fork и автоотправки.
Если полный URI длиннее 1800 символов, по этому нажатию весь draft копируется
в системный буфер, чат открывается без query; вставьте Ctrl+V и отправьте.
Вложения идут текстом как локальные пути/контекст, не карточками Desktop.
Draft/вложения/очередь в VS Code сохраняются. ПОСЛЕ ОТПРАВКИ В DESKTOP УДАЛИТЕ
ЭЛЕМЕНТ ОЧЕРЕДИ ВРУЧНУЮ, чтобы не отправить его повторно. Чужой процесс не
останавливается, lock не снимается. Установленный parser поддерживает
prefillPrompt; реальный Desktop с пользовательской историей не открывался.
Настоящий VS Code с двумя native App Server и stub Desktop opener проверил
кнопки и сохранение данных; OS openExternal/clipboard проверены Node-стабами.
