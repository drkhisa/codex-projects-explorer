CODEX PROJECTS EXPLORER 0.5.5 — MAC

1. ПРОВЕРИТЬ macOS
 → Об этом Mac. Актуальный VS Code требует macOS 12 или новее.
На macOS Catalina 10.15 этот комплект с актуальными зависимостями не обещает
работать; совместимость старых версий здесь не проверена.

2. УСТАНОВИТЬ VS CODE
Откройте https://code.visualstudio.com/download
Скачайте macOS Universal. Откройте DMG, перенесите Visual Studio Code.app
в Программы / Applications. Запустите редактор из Программ.

3. УСТАНОВИТЬ ОФИЦИАЛЬНЫЙ CODEX
В VS Code нажмите Cmd+Shift+X. В поиск вставьте @id:openai.chatgpt
Установите Codex от OpenAI. Откройте его панель, нажмите Sign in with ChatGPT,
войдите в свой аккаунт в браузере и вернитесь в редактор.

4. УСТАНОВИТЬ НАШЕ РАСШИРЕНИЕ
Распакуйте общий архив, откройте папку Mac.
Дважды нажмите Установить.command. Это сценарий, который запускается через
Терминал; вручную вводить команды для установки VSIX не требуется.
Он ищет VS Code в Программах и при необходимости предлагает выбрать редактор.
Устанавливается только наше расширение VS Code, не браузерный компонент.
После сообщения об успехе полностью закройте VS Code через Cmd+Q и откройте заново.
Сценарий не подписан и на настоящем Mac здесь не запускался. Если система
не разрешает его запуск, используйте ручную установку VSIX ниже.

РУЧНАЯ УСТАНОВКА VSIX
В VS Code нажмите Cmd+Shift+P. В появившейся строке команд введите
Extensions: Install from VSIX...
Нажмите Enter, выберите codex-projects-explorer-0.5.5.vsix из папки Mac,
нажмите Установить. Закройте редактор через Cmd+Q и откройте снова.

5. УСТАНОВИТЬ GIT ДЛЯ ПРОСМОТРА ИЗМЕНЕНИЙ
Если Git не установлен, откройте Программы → Утилиты → Терминал и выполните:
xcode-select --install
В появившемся окне нажмите Установить и дождитесь завершения.
Если инструменты уже установлены, повторная установка не нужна.

6. НАЧАТЬ РАБОТУ
Слева нажмите Проекты Codex. Раздел Codex читает локальную историю этого Mac.
Сам по себе вход в тот же аккаунт не загружает историю с Windows.
Новый чат вне проекта: ＋ Новый чат → Новый чат вне проекта.
Новый чат в проекте: наведите на проект и нажмите ＋ справа.
Порядок: закреплённые чаты → категории → остальные чаты → скиллы.
Закреплённый чат из категории показан единожды сверху; после открепления
возвращается в категорию. Ручной порядок закрепов запоминается.
Кнопка Изменения в чате открывает дерево файлов и изменения Git справа.

7. БРАУЗЕРНОЕ РАСШИРЕНИЕ — ГРАНИЦА ЭТОЙ СБОРКИ
В папке Mac приложены browser-bridge и Codex-Projects-Browser-0.5.5.zip.
Установщика браузерного расширения двойным кликом с выбором браузера здесь
ЕЩЁ НЕТ. Для обычной внешней установки в Chrome на macOS требуется публикация
в Chrome Web Store. Компонент ещё не опубликован; карточки и ID нет.
ZIP/CRX не устанавливается в Chrome просто двойным кликом. Установить.command
не объявляет браузерное расширение установленным. Политики браузеров не меняются.
Ручной способ описан в browser-bridge/ПРОЧИТАЙ.txt; это временный путь
для разработчика, а не запрошенная обычная установка.
Safari/Firefox этим компонентом не поддерживаются.

Если компонент уже установлен: Cmd+Shift+P → Codex Projects: Подключить онлайн
ChatGPT → Подключить браузер. Соединение запоминается. Если страница открылась
в Safari, перенесите её адрес в браузер с установленным компонентом.
Передаётся часть загруженных страниц, не весь серверный архив. Отправка,
выбор модели и вложения онлайн-чатов остаются в исходном ChatGPT.

8. ПРОВЕРКА
В расширениях должна отображаться версия Codex Projects Explorer 0.5.5.
Если история пуста: ⋯ в Проектах Codex → Выбрать папку данных Codex.
Обычный путь: ~/.codex. В диалоге Finder путь можно ввести через Cmd+Shift+G.
Если нет проектов/чатов с другого компьютера, это не доказывает их отсутствие
в аккаунте: локальное хранилище не синхронизируется автоматически.

Фактические проверки выпуска перечислены в общем файле СНАЧАЛА ПРОЧИТАЙ.txt.
Синтаксис bash, запуск сценария и VS Code Extension Host на настоящем Mac,
установка в браузере и авторизованная онлайн-история не проверялись.
