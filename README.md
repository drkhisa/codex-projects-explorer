# Codex Projects Explorer 0.5.5

Расширение VS Code для проектов и чатов Codex: история переписок, чат в центральной вкладке, файлы и изменения Git, категории и закрепления. Экспериментальный браузерный мост ChatGPT передаёт данные загруженных страниц; полная онлайн-история и отправка в онлайн ChatGPT из VS Code пока не реализованы.

GitHub: [drkhisa/codex-projects-explorer](https://github.com/drkhisa/codex-projects-explorer). Возможности и установка расширения: [extension/readme.md](extension/readme.md).

В **0.5.5** новый чат получает подпись из первого принятого сервером текстового сообщения сразу в дереве, вкладке и заголовке, без ручного обновления и события переименования. Следующие сообщения её не заменяют, отклонённая отправка название не меняет. Заданное имя приоритетнее сокращённого текста запроса; генерация имени моделью не добавлялась. Фоновое обновление усваивает имя и текст первого сообщения с сервера, а пустые снимки и запоздалый ответ опроса не стирают уже полученную подпись и свежее переименование. История и черновик сохраняются. Версия 0.5.4 синхронизировала только уже готовые метаданные: путь от первой отправки до названия в ней оставался неполным.

При выпуске прошли все 22 синтетических теста (9 на жизненный цикл и 13 на название), проверка исходного архива, JSON, точек входа и синтаксиса 31 JS-файла. Проверены содержимое и структура ZIP/VSIX, SHA-256, воспроизводимость архивов и отказ перезаписывать готовый выпуск.

В чате разработки пройдена интеграционная UI-проверка в настоящем VS Code 1.145.2 с изолированным профилем и нативным App Server. Нажатие реальной кнопки отправки завершило синтетический ход: подписи дерева, вкладки, документа и заголовка совпали с первым сообщением. Серверное переименование обновило их, сохранив неотправленный черновик. Использовались только синтетические данные и локальный HTTP/SSE-ответ на 127.0.0.1. Настоящая модель, аккаунт, обычный пользовательский профиль, установщики, macOS, браузер и сопряжение не проверялись.

Общий комплект: `builds/0.5.5/Codex-Projects-All-0.5.5.zip`; рядом находятся отдельные VSIX, ZIP браузерного компонента и `SHA256SUMS`. Результаты сборки хранятся локально и не добавляются в Git.

## Разработка и проверки

Локальная папка проекта: `J:\ChatGPT\VS Code PlugIn`. Новые локальные файлы проекта должны оставаться внутри неё.

| Папка | Содержимое |
| --- | --- |
| `archives/` | Неизменяемый исходный ZIP и SHA-256 |
| `extension/` | Рабочие исходники VS Code и `browser-bridge/` |
| `installers/` | Установочные сценарии, инструкции и шаблон метаданных Windows/macOS |
| `packaging/` | Метаданные текущего VSIX и общая инструкция выпуска |
| `docs/` | Разбор исходника, роли агентов и оригинальные инструкции |
| `scripts/` | Настройка временных папок, проверка, регрессионные тесты и упаковка |
| `builds/` | Сборки по версиям и SHA-256; результаты исключены из Git |
| `reports/` | Локальные отчёты; результаты исключены из Git |
| `.local/` | Временные файлы и кеши; исключены из Git |

Из корня в PowerShell, каждую команду отдельно:

```powershell
rtk proxy powershell -NoProfile -Command '. .\scripts\Enter-Project.ps1; rtk proxy node scripts/verify.mjs'
rtk proxy powershell -NoProfile -Command '. .\scripts\Enter-Project.ps1; rtk proxy node --test scripts/chat-lifecycle.test.cjs scripts/chat-title.test.cjs'
```

Для последующей работы в уже открытом терминале выполнить `. .\scripts\Enter-Project.ps1`, затем запускать команды через `rtk`.

Проверки требуют установленный Node.js, не устанавливают пакеты и не запускают плагин. Регрессионные тесты используют синтетические данные внутри проекта. Исходные `npm test`, `npm run package` и `npm run build:installer` не работают: указанные в них файлы не вошли в поставку.

Правило **MAJOR.MINOR.PATCH**, команда упаковки на Python и границы проверки: [docs/RELEASE.md](docs/RELEASE.md). При изменении поведения всегда обновляется README; при каждом выпуске сверяются версия, возможности, инструкции, проверки и описание репозитория GitHub.

## Исходная поставка 0.5.2

Проект восстановлен из оригинального комплекта **0.5.2**. Неизменяемый ZIP и его SHA-256 сохранены в `archives/`, исходные инструкции — в `docs/original/`. Доработки ведутся в `extension/`; оригинальный архив не изменяется. Подробности: [разбор исходной поставки](docs/BASELINE.md).

Правила работы: [AGENTS.md](AGENTS.md), [рабочие чаты](docs/CHATS.md), [роли агентов](docs/agents/). Исходная лицензия расширения: [MIT](extension/LICENSE.txt).
