# Codex Projects Explorer

Рабочий проект плагина VS Code, восстановленный из поставки **0.5.2**. Репозиторий хранит оригинальный архив, читаемый код расширения, браузерный мост, установщики и инструкции агентам.

Приватный GitHub: [drkhisa/codex-projects-explorer](https://github.com/drkhisa/codex-projects-explorer).

Локальная папка проекта: `J:\ChatGPT\VS Code PlugIn`. Новые локальные файлы проекта должны оставаться внутри неё.

| Папка | Содержимое |
| --- | --- |
| `archives/` | Неизменяемый исходный ZIP и SHA-256 |
| `extension/` | Рабочие исходники VS Code и `browser-bridge/` |
| `installers/` | Исходные установщики Windows и macOS |
| `packaging/` | Метаданные исходного VSIX |
| `docs/` | Разбор исходника, роли агентов и оригинальные инструкции |
| `scripts/` | Настройка локальных временных папок и проверка |
| `builds/` | Сборки по версиям и SHA-256; результаты исключены из Git |
| `reports/` | Локальные отчёты; результаты исключены из Git |
| `.local/` | Временные файлы и кеши; исключены из Git |

## Начало работы

Из корня в PowerShell:

```powershell
rtk proxy powershell -NoProfile -Command '. .\scripts\Enter-Project.ps1; node scripts/verify.mjs'
```

Для последующей работы в уже открытом терминале выполнить `. .\scripts\Enter-Project.ps1`, затем запускать команды через `rtk`.

Проверка требует установленный Node.js, не устанавливает пакеты и не запускает плагин. Она проверяет архив, структуру и синтаксис; функциональные тесты в исходной поставке отсутствуют. Оригинальные `npm test` и команды сборки пока не работают: указанные в них файлы не вошли в архив.

Выпуск **0.5.3**, правило **MAJOR.MINOR.PATCH**, регрессионные тесты и новая упаковка без npm: [docs/RELEASE.md](docs/RELEASE.md).

Доработки делать в распакованных файлах, оригинальный ZIP не менять. Подробности: [разбор исходной поставки](docs/BASELINE.md), [правила агентов](AGENTS.md), [рабочие чаты](docs/CHATS.md), [роли](docs/agents/).

Документация самого плагина: [extension/readme.md](extension/readme.md). Исходная лицензия расширения сохранена в [extension/LICENSE.txt](extension/LICENSE.txt).
