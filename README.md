# Codex Projects Explorer 0.6.0

Расширение VS Code для проектов и чатов Codex: история, центральный чат, файлы и изменения Git, категории и архив по проектам. Браузерный мост показывает доступные проекты ChatGPT и позволяет явно отправить текст в выбранный исходный онлайн-чат.

GitHub: [drkhisa/codex-projects-explorer](https://github.com/drkhisa/codex-projects-explorer). Подробная установка и возможности: [extension/readme.md](extension/readme.md).

Скачать **[0.6.0](https://github.com/drkhisa/codex-projects-explorer/releases/tag/v0.6.0)**:
[комплект Windows/Mac](https://github.com/drkhisa/codex-projects-explorer/releases/download/v0.6.0/Codex-Projects-All-0.6.0.zip),
[VSIX](https://github.com/drkhisa/codex-projects-explorer/releases/download/v0.6.0/codex-projects-explorer-0.6.0.vsix),
[браузерный ZIP](https://github.com/drkhisa/codex-projects-explorer/releases/download/v0.6.0/Codex-Projects-Browser-0.6.0.zip),
[SHA256SUMS](https://github.com/drkhisa/codex-projects-explorer/releases/download/v0.6.0/SHA256SUMS).
После установки VSIX перезагрузите окно VS Code. Для онлайн-возможностей обновите также браузерный компонент и все открытые вкладки ChatGPT: старый протокол не поддерживает новые команды. Установка браузерного компонента остаётся ручной.
Предыдущие выпуски: [0.5.5](https://github.com/drkhisa/codex-projects-explorer/releases/tag/v0.5.5), [0.5.4](https://github.com/drkhisa/codex-projects-explorer/releases/tag/v0.5.4), [0.5.3](https://github.com/drkhisa/codex-projects-explorer/releases/tag/v0.5.3).

В 0.6.0:

- После ответа расширение освобождает idle writer и ждёт подтверждения сервера. Другой клиент может продолжить чат; работающий чужой клиент не прерывается, при конфликте черновик и вложения сохраняются.
- **Ctrl+V** добавляет скопированные изображения, текстовые файлы и документы в локальный чат Codex. До 8 элементов на сообщение; за одну вставку суммарно до 50 МБ, изображение до 10 МБ, текстовый файл до 256 КБ, документ до 50 МБ. Вставленные файлы сохраняются для истории. Ctrl+C копирует, Ctrl+V вставляет.
- Поле ввода сохраняет компактную высоту с внутренней прокруткой. Длинный запрос можно открыть кнопкой **«Развернуть / Свернуть»**, сохранив текст и курсор; после успешной отправки поле снова компактное.
- Сохранённые названия, короткие preview и другие метаданные сразу показывают дерево после запуска. Неизменённые локальные summaries используются повторно; каталог сверяется в фоне для новых, изменённых, удалённых и архивированных записей. RPC-запросы остаются нужны.
- Сбор доступных проектов ChatGPT сохраняет связь чатов с проектами. Кнопка **«Отправить в ChatGPT»** передаёт только введённый текст через обычную форму исходного чата. При неизвестном исходе автоматического повтора нет. Полнота аккаунта не гарантируется; онлайн-вложения, выбор модели из VS Code, архив и удаление онлайн-чатов не добавлены.
- Индикатор активности виден у чата, его категории, проекта и родительской группы, в том числе при свёрнутом дереве.
- **«Архив Codex»** в переключателе разделов показывает архивные чаты по проектам. Можно восстановить чат или удалить навсегда с именованным подтверждением. Сервер удаляет историю и связанные дочерние чаты; файлы проекта сохраняются. Для отправки архивный чат сначала нужно восстановить.

Проверки выпуска: **67 Node-тестов**, **31 проверка синтаксиса JS**, 8 Python-тестов загрузки baseline и публикации, проверки структуры, ZIP/VSIX и SHA-256. В настоящем VS Code 1.145.2 с изолированным профилем и локальным синтетическим HTTP/SSE-провайдером проверены заголовки и черновик, передача writer второму нативному App Server, вставка и отправка PNG/TXT, архив по проектам, удаление синтетического чата с сохранением другого чата и файлов проекта. Поле осталось высотой 76 px при 120 строках, разворачивание и сворачивание сохранили курсор. Повторный запуск показал дерево из кэша до ответа сервера.

Браузерная часть проверена на синтетическом DOM и локальном HTTP-мосте. Настоящая модель, аккаунт ChatGPT, обычный пользовательский профиль, macOS, установщики и установка/сопряжение браузера не проверялись. Вставка проверена реальным ClipboardEvent/DataTransfer в webview; физическое нажатие Ctrl+V и системные форматы буфера не проверялись. Пользовательская история не использовалась; тестовое удаление касалось только синтетического чата.

Готовые пакеты находятся в GitHub Releases и локально в `builds/0.6.0/`. Бинарные поставки, кеши и QA-отчёты не добавляются в Git.

## Разработка и проверки

Локальная папка проекта: `J:\ChatGPT\VS Code PlugIn`. Новые локальные файлы проекта должны оставаться внутри неё.

| Папка | Содержимое |
| --- | --- |
| `archives/` | Локальный baseline из Release v0.5.2; исключён из Git |
| `extension/` | Рабочие исходники VS Code и `browser-bridge/` |
| `installers/` | Установочные сценарии, инструкции и шаблон метаданных Windows/macOS |
| `packaging/` | Метаданные VSIX, закреплённый baseline.json и инструкция выпуска |
| `docs/` | Разбор исходника, роли агентов и оригинальные инструкции |
| `scripts/` | Настройка временных папок, проверки, тесты, упаковка и публикация Releases |
| `builds/` | Сборки по версиям и SHA-256; результаты исключены из Git |
| `reports/` | Локальные отчёты; результаты исключены из Git |
| `.local/` | Временные файлы и кеши; исключены из Git |

Из корня в PowerShell, каждую команду отдельно:

```powershell
rtk proxy powershell -NoProfile -Command '. .\scripts\Enter-Project.ps1; rtk proxy python scripts/fetch-baseline.py'
rtk proxy powershell -NoProfile -Command '. .\scripts\Enter-Project.ps1; rtk proxy node scripts/verify.mjs'
rtk proxy powershell -NoProfile -Command '. .\scripts\Enter-Project.ps1; rtk proxy node --test --test-reporter=dot (Get-ChildItem -LiteralPath scripts -Filter *.test.cjs).FullName'
```

Для последующей работы в уже открытом терминале выполнить `. .\scripts\Enter-Project.ps1`, затем запускать команды через `rtk`.

Загрузка baseline требует Python 3 и доступа к GitHub Releases при первом запуске; при наличии проверенного файла сеть не используется. ZIP скачивается в локальную `archives/`, размер и SHA-256 сверяются с отслеживаемым `packaging/baseline.json` до записи. Существующий исходник не перезаписывается. Проверки требуют установленный Node.js, не устанавливают пакеты и не запускают плагин. Регрессионные тесты используют синтетические данные внутри проекта. Исходные `npm test`, `npm run package` и `npm run build:installer` не работают: указанные в них файлы не вошли в поставку.

Правило **MAJOR.MINOR.PATCH**, команда упаковки на Python и границы проверки: [docs/RELEASE.md](docs/RELEASE.md). При изменении поведения всегда обновляется README; при каждом выпуске сверяются версия, возможности, инструкции, проверки и описание репозитория GitHub.
